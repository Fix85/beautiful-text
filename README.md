# Text Krasiviy

Мод для Minecraft Fabric, который автоматически форматирует ваши сообщения в чате цветными кодами Minecraft.

## Описание

Text Krasiviy автоматически добавляет настроенный префикс форматирования ко всем сообщениям в чате. Это позволяет сделать ваши сообщения красивыми без необходимости каждый раз вводить цветовые коды вручную.

## Возможности

- ✅ **Автоматическое форматирование** - все сообщения автоматически получают настроенный префикс (по умолчанию `&6&l` - желтый жирный текст)
- ✅ **Обработка сообщений с восклицательным знаком** - сообщения, начинающиеся с `!`, сохраняют восклицательный знак
- ✅ **Пропуск команд** - команды, начинающиеся с `/`, не обрабатываются модом
- ✅ **Настраиваемый префикс** - вы можете настроить префикс форматирования через Mod Menu

## Примеры работы

| Ввод | Результат |
|------|-----------|
| `123` | `123` (желтый жирный) |
| `!123` | `!123` (восклицательный знак + желтый жирный) |
| `/help` | `/help` (не обрабатывается, команда) |

## Установка

1. Убедитесь, что у вас установлены:
   - Minecraft 1.21.4
   - Fabric Loader 0.17.2 или выше
   - Fabric API
   - Java 21 или выше

2. Скачайте последний релиз из раздела [Releases](https://github.com/Fix85/text-krasiviy/releases)

3. Поместите файл `text-krasiviy-1.0.0.jar` в папку `mods` вашего клиента Minecraft

4. Запустите игру

## Настройка

1. Откройте меню настроек Minecraft
2. Перейдите в раздел **Mods**
3. Найдите **Text Krasiviy** и нажмите на иконку настроек
4. Измените префикс на нужный вам (например, `&c&l` для красного жирного текста)

### Цветовые коды Minecraft

- `&0` - Черный
- `&1` - Темно-синий
- `&2` - Темно-зеленый
- `&3` - Темно-голубой
- `&4` - Темно-красный
- `&5` - Пурпурный
- `&6` - Золотой/Оранжевый
- `&7` - Серый
- `&8` - Темно-серый
- `&9` - Синий
- `&a` - Зеленый
- `&b` - Голубой
- `&c` - Красный
- `&d` - Розовый
- `&e` - Желтый
- `&f` - Белый

### Коды форматирования

- `&l` - Жирный
- `&o` - Курсив
- `&n` - Подчеркнутый
- `&m` - Зачеркнутый
- `&k` - Случайные символы
- `&r` - Сброс форматирования

## Требования

- **Minecraft**: 1.21.4
- **Fabric Loader**: >= 0.17.2
- **Fabric API**: Любая версия для 1.21.4
- **Java**: >= 21
- **Mod Menu** (рекомендуется): Для настройки через GUI

## Сборка из исходников

```bash
git clone https://github.com/Fix85/text-krasiviy.git
cd text-krasiviy
./gradlew build
```

Готовый JAR файл будет находиться в `build/libs/`
